# FEBio Mechanobiological Material

Mechanobiological multiphasic material for FEBio.

## Description

This repository contains a custom FEBio material implementing a
mechanobiological model of intervertebral disc degeneration.

## Features

- Multiphasic material formulation
- Nutrient transport
- Aerobic and anaerobic metabolism
- ECM biosynthesis and degradation
- Evolution of referential fixed charge density
- Degeneration-dependent diffusivity
- Degeneration-dependent OCF stiffness

## Files

- `Mechanobiological.h` — class declarations
- `Mechanobiological.cpp` — model implementation

## Requirements

- FEBio
- FEBio SDK
- Visual Studio
